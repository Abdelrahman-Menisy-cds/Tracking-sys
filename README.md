# Heya Fawda?

**هي فوضى؟** — Arabic-first employee requests and time-tracking system.

## Project stack

- Backend: Django + Django REST Framework
- Frontend: React + TypeScript + Vite
- Database: PostgreSQL
- Workflow: BMAD BMM
- Appearance: System (default), Light, and Dark
